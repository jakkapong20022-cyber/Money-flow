ไม่ต้องติดตั้งแพ็กเกจเพิ่ม (ใช้ Node.js 18+ ล้วน) ข้อมูลเก็บที่ `data/db.json`

```bash
node server.js            # เปิด http://localhost:3000
node test/test.js         # รันชุดทดสอบ (41 เช็ก)
```

สมัครสมาชิก → ตั้งค่าครอบครัวและสมาชิก → ใช้งานได้ทันที (ติดตั้งเป็นแอปบนมือถือได้ผ่าน "เพิ่มไปยังหน้าจอหลัก")

## ฟีเจอร์ล่าสุด
- **หนี้สิน** (เมนูกลาง-ขวา): เพิ่มค่างวด/บัตรเครดิต/เงินยืม + วันครบกำหนด · กด "จ่ายงวดนี้" → บันทึกเป็นรายจ่ายและเลื่อนงวดถัดไปอัตโนมัติ
- **ลงปฏิทินโทรศัพท์**: ปุ่ม 📅 สร้างไฟล์ .ics (กิจกรรม 09:00, ซ้ำทุกเดือนตามจำนวนงวด, เตือนล่วงหน้า + วันครบกำหนด) หรือเปิด Google Calendar · โหมดเซิร์ฟเวอร์มีลิงก์ `webcal://` สมัครรับครั้งเดียวแล้วอัปเดตเอง
- LINE: พิมพ์ `หนี้` ดูรายการ · เตือนครบกำหนด 08:00 น.
- รูปสมาชิก (อัปโหลดได้) · งบประมาณรายหมวด (ตั้งที่ หมวดหมู่ → ✎) · ภาพรวมแบบกราฟ
- สลิปที่สแกน: เก็บเฉพาะข้อมูลที่อ่านได้ (ธนาคาร ผู้โอน ผู้รับ เวลา เลขอ้างอิง) ไม่เก็บไฟล์รูป
- ไฟล์เดียว: `node build/build-html.js` → `dist/family-budget.html` (ใช้งานในเครื่อง ไม่ต้องมีเซิร์ฟเวอร์)

## ตัวแปรสภาพแวดล้อม
| ตัวแปร | หน้าที่ |
|---|---|
| `PORT` | พอร์ต (ค่าเริ่มต้น 3000) |
| `PUBLIC_URL` | URL แบบ HTTPS ของเซิร์ฟเวอร์ ใช้แสดง Webhook URL เช่น `https://budget.example.com` |
| `ANTHROPIC_API_KEY` | เปิดระบบอ่านสลิป/ใบเสร็จด้วย Claude vision (ทั้งในเว็บและ LINE) |
| `ANTHROPIC_MODEL` | โมเดลที่ใช้อ่านสลิป (ค่าเริ่มต้น `claude-sonnet-5-5`) |
| `DATA_DIR` | โฟลเดอร์เก็บข้อมูล |
| `LINE_CHANNEL_SECRET`, `LINE_CHANNEL_ACCESS_TOKEN` | (ทางเลือก) ค่า default ถ้าไม่ตั้งในหน้า ตั้งค่า |

## เชื่อม LINE OA
1. ที่ https://developers.line.biz สร้าง Provider → Messaging API channel (LINE OA)
2. ในแอป: **ตั้งค่า → LINE Official Account** วาง Channel secret และ Channel access token (long-lived) แล้วกดบันทึก
3. ที่ LINE Developers ตั้ง **Webhook URL** เป็นค่าที่แอปแสดง (`https://โดเมนคุณ/webhook/line/<familyId>`) → กด Verify, เปิด *Use webhook*, ปิด *Auto-reply messages*
   - ทดสอบในเครื่อง: `cloudflared tunnel --url http://localhost:3000` หรือ `ngrok http 3000` แล้วตั้ง `PUBLIC_URL`
4. ในแอปกด "สร้างรหัส" ของสมาชิกแต่ละคน → ให้เจ้าตัวสแกน QR ด้วย LINE แล้วกดส่งข้อความ `ผูก 123456` ที่ขึ้นรอในแชท OA (หรือพิมพ์ส่งเอง)

### คำสั่งใน LINE
`จ่าย 120 ข้าวมันไก่` · `รับ 5000 เงินเดือน` · `กาแฟ 65` (พิมพ์สั้น = รายจ่าย) · `สรุป` · `วันนี้` · `ลบล่าสุด` · `เปลี่ยนเป็นรายรับ` · `วิธีใช้`
**ส่งรูปสลิป/ใบเสร็จ** → อ่านยอด วันที่ ผู้รับ ธนาคาร เลขอ้างอิง → เดาหมวดหมู่ → บันทึกให้ (กันสลิปซ้ำด้วยเลขอ้างอิง, แปลงปี พ.ศ. เป็น ค.ศ. อัตโนมัติ)

### การแจ้งเตือน
มีรายการใหม่ → แจ้งสมาชิกคนอื่น · ใช้งบ 80%/100% → เตือนทุกคน · สรุปรายวัน 20:00 น. (เปิด/ปิดได้ในแอป)

## ความปลอดภัย
รหัสผ่านเข้ารหัส scrypt · webhook ตรวจลายเซ็น HMAC-SHA256 ทุกครั้ง · จำกัดความถี่ล็อกอิน · ควรรันหลัง HTTPS เสมอ
